IRL 5 (BAGIAN 2) : DEVELOPMENT DASHBOARD & IMPLEMENTASI FITUR TERBANGUN
DASHBOARD PUBLIK & ARSITEKTUR SPA
1. Arsitektur Single Page Application (SPA) AKTIF
Dibangun menggunakan CodeIgniter 3 di backend serta Vanilla JS + CSS3 modern di frontend. Menghasilkan antarmuka yang sangat responsif, stabil, bebas lag, dan optimal untuk layar monitor TV pabrik maupun browser desktop.
2. Instant Server-Side Pre-Hydration 0ms DELAY
Menyematkan payload data awal secara langsung ke variabel DOM (INITIAL_DASHBOARD_PAYLOAD) saat HTML disajikan. Mengeliminasi efek blank screen dan loading spinner saat halaman pertama kali diakses.
3. Multi-Delivery Scope Switcher 1, 2, 4, 6 DELIVERY
Memungkinkan pengguna beralih fleksibel antara cakupan 1, 2, 4, atau 6 delivery. Pilihan periode aktif disimpan otomatis ke dalam browser cookie (heatDeliveryCount) untuk kenyamanan pengguna.
4. Dynamic Excel Report Exporter DYNAMIC .XLS
Tombol ekspor laporan Material To Load yang menghasilkan file spreadsheet (.xls) terformat rapi yang menyesuaikan label periode aktif yang sedang dipilih secara dinamis.
5. Wall-Clock Aligned Auto-Refresh :00 & :30 SYNC
Mekanisme fetch data otomatis yang tersinkronisasi presisi dengan jam dinding pada menit :00 dan :30 setiap jam, dilengkapi visual live pulse indicator untuk memastikan data selalu mutakhir.
PANEL ADMIN TERPADU & ENGINE ANALYTICS
1. Panel Admin Terpadu GM (Protected Session) SECURE AUTH
Modul administrasi terlindung autentikasi session portal (tbl_login) dengan sidebar navigasi interaktif tanpa reload untuk manajemen konfigurasi sentral sistem.
2. Manajemen Katalog Style SMV CUSTOM SMV
Antarmuka komprehensif dengan pagination, search bar filter, input nilai Standard Minute Value (SMV) per style artikel, dan toggle visibilitas style yang ditampilkan di dashboard publik.
3. Mode Direct Aktual & Override Kapasitas HYBRID CALC
Kemampuan beralih fleksibel antara input manual angka Direct Aktual oleh supervisor atau mengandalkan rumus kalkulasi otomatis sistem.
4. Kalender Hari Kerja & Manajemen Shift INTERACTIVE UI
Antarmuka kalender visual interaktif untuk mengatur hari kerja penuh (1), libur (0), setengah hari (0.5), dan seperempat hari (0.25) per periode delivery aktif.
5. Mesin Evaluasi Analytics & Action Plan (CAP) AI INSIGHT
Sistem cerdas yang mengevaluasi kepatuhan delivery lampau, memberikan status kondisi operasional (Good / Watch / Risk), serta merumuskan Corrective Action Plan harian secara otomatis.
